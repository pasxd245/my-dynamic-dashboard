MDD — design previews

Brainstorming aids for the product UI, grouped by domain. Click any preview to open it in this tab; each preview has a ← Preview index button bottom-left to return.

Data management

  • Workspaces

    R11 shell + grid

    data-management/workspace-shell.preview.html

    Master-layout chrome (sidebar, top-bar, breadcrumb, page header, page card) with the Workspaces card grid as content. Sidebar fold/unfold + sub-menu flyout interactions live here. Click any workspace card to drill into the Datasets preview.

  • Datasets

    R14 table list

    data-management/datasets.preview.html

    Datasets page (sub-menu peer of Workspaces, R14 reframe) — sortable table of committed datasets across workspaces, with filter dropdown and search. + Upload navigates to the upload wizard. State toggle flips empty / populated.

  • Upload wizard

    R14 3-step page · sub-route of Datasets

    data-management/upload.preview.html

    Full-page wizard at /data-management/datasets/new — Source (workspace + file) → Preview (parsed schema + sample rows) → Confirm (name + create). State toggle includes a parse-failed variant of step 2.

  • Dataset detail

    R33 paged row inspector · sub-page of Datasets

    data-management/dataset-detail.preview.html

    Per-dataset page at /data-management/datasets/:id — header with format chip + Actions (Rename / Delete), metadata strip, debounced row-substring search bar, paged data table with dtype-badged column headers and dtype-aware cell rendering. State toggle flips populated / loading / 404-deleted / zero-rows / no-match. The R34→R36 implementation chain builds against this design.

  • CRUD hygiene

    R23 rename + delete · workspaces + datasets

    data-management/crud-hygiene.preview.html

    Rename + delete affordances on both Workspace cards and the Datasets table, plus the cascade rule for non-empty workspaces. Toggle the surface (workspaces / datasets) and modal state (rename, loading, 409 error, delete dataset, delete workspace, blocked) at the bottom of the page to walk all six visible states the HIxAI loop revolved around.

Navigation between previews: click a workspace card on the Workspaces preview to open Datasets filtered to that workspace; click + Upload on Datasets to enter the Upload wizard; click "Workspaces" or "Datasets" in any sidebar to navigate. Each preview also has a ← Preview index button bottom-left that brings you back here. Sidebar sub-items above are the same destinations — pick whichever navigation feels right.
